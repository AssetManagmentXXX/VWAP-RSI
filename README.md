# VWAP-RSI
Señales VWAP y RSI 40 Periodos

Las señales de este script se basan en la ruptura de la primera desviación estandar
y regreso al VWAP con una vela de rechazo para lanzar una señal de compra o venta

Tiene tambien incorporado una señal de compra o venta para un RSI de 40 Periodos cuando esta
en 70 o 30 respectivamente
